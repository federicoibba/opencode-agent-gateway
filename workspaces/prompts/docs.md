Write or update the documentation for what I describe, using the `docs-writer`
skill:

- Lead with the task and the shortest working path.
- Include runnable examples; no invented flags or APIs.
- Cover prerequisites, the happy path and common errors.

Say what you could not verify from the code and where you relied on general
knowledge.
