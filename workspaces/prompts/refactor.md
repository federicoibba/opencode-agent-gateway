---
name: Refactor
description: Simplify or clean up code while preserving behaviour.
tags: [refactoring, tech-debt]
---

Refactor what I share using the `refactoring` skill:

1. Identify dead code, duplication and needless complexity.
2. Make small, reversible changes that preserve behaviour.
3. Keep the tests as the safety net; run them or ask for them.

List what you would remove or simplify, in order, and call out the risk of each
step. Do not mix behaviour changes into a refactor.
