---
name: Plan Implementation
description: Turn a spec or design into phased, file-level implementation steps.
tags: [planning, delivery]
---

Produce an implementation plan using the `planning` skill:

- Phases ordered by dependency; each step names the file(s) and the action.
- Dependencies, risks and mitigations per step.
- A testing strategy: unit, integration and end-to-end.
- Success criteria.

Read the relevant code first, and flag anything you could not verify.
