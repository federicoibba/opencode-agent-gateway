---
name: Write a Spec
description: Turn a request into a spec with scope, non-goals and acceptance criteria.
tags: [product, spec]
---

Write a specification for what I describe, using the `spec-writing` skill:

1. **Problem** — the user, the job to be done, and why now.
2. **Scope** — the smallest shippable slice, and explicit non-goals.
3. **Acceptance criteria** — Given/When/Then, including edge cases.
4. **Metrics** — how we will know it worked.

Ask only the questions that would change the spec. End with assumptions and open
questions.
